# ethics-distill

Distilling the Ethics Panel's seven-seat deliberation into a small model, to test whether
ethical reasoning can be carried in weights rather than supplied in context.

## Design (settled 2026-09-21)

- Teacher: Claude Sonnet 5 for training data, Claude Opus 5 for the evaluation gold set.
- Seats: Kant (historical), Mill, Aristotle, Rawls, Hegel, Spinoza, Aquinas. A contemporary-Kantian
  view is generated by a separate call and attached to the Kant seat as an annotation; it is not a
  voice in the panel aggregate.
- Synthesis (agreements, dissenters, split label) is computed in code from seat outputs; only the
  crux is generated.
- Student: Qwen3-4B-Base, one LoRA adapter per seat plus one merged model; Qwen3-8B-Base as a
  size-scaling arm; Qwen3-4B (instruct) for the base-vs-instruct comparison.
- Scaling curve in doubling tiers (250, 500, 1000 ...), one teacher recipe throughout.
- Held out of training entirely: clinical and biotech scenarios.
- Scenarios are generic; no client or company situations.
- Budget for the first stage (1,000 training cases, 300 eval cases, adapters at three tiers): $200.

## Layout

- distill/         pipeline code (generator, panel runner, synthesis, training data builder)
- data/scenarios/  generated cases (committed)
- data/seats/      teacher outputs (not committed; large)
- data/eval/       frozen evaluation set (not committed)
- results/         metrics and reports
- docs/            taxonomy, decisions, spend log

Pilot code and results live in ../ethics-panel/research/pilot.
